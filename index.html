Privacy policy

Doclune processes documents on your device. The app does not operate a document-upload server or include advertising or analytics services. It locally stores document names, file references, document hashes, favorites, reading positions, last-opened times and language preferences.

Reading may create a temporary file in app storage. Temporary files are deleted when reading closes normally; interrupted sessions can leave cached files. A permanent copy is kept only if you choose Save in app. Removing a history record does not delete your original file. Uninstalling the app removes app-local data subject to operating-system behavior.

Copying text places the selected document text on the system clipboard. File providers such as cloud drives process data under their own policies. OS backups, app stores and beta testing services may process information separately from Doclune.

Doclune uses a device-local loopback connection to display documents. It does not send these documents to a remote server.

개인정보 처리 안내

독룬은 문서를 기기에서 처리하며 문서 업로드 서버, 광고 또는 분석 서비스를 사용하지 않습니다. 파일명·접근 참조·문서 해시·즐겨찾기·읽던 위치·최근 열기 시각·언어 설정은 기기에 저장합니다.

읽기를 위해 임시 파일이 생성될 수 있고 정상적으로 읽기를 종료하면 삭제합니다. 비정상 종료 시 캐시가 남을 수 있습니다. 영구 사본은 사용자가 ‘앱에 저장’을 선택한 경우에만 보관합니다. 기록 삭제는 원본 파일을 삭제하지 않습니다. 앱 삭제 시 운영체제 동작에 따라 앱 내부 데이터가 제거됩니다.

복사한 문서 내용은 시스템 클립보드에 저장됩니다. 클라우드 제공자, 운영체제 백업, 앱 스토어 및 베타 테스트 서비스는 각자의 정책에 따라 별도로 정보를 처리할 수 있습니다. 문서 표시를 위한 통신은 기기 내부의 루프백 연결이며 원격 서버로 문서를 전송하지 않습니다.
